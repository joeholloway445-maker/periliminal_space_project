## 9. Supabase Routing & Data Schema

### 9.1 Core Tables

```sql
-- Behavioral telemetry ingress
CREATE TABLE telemetry_stream (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id TEXT NOT NULL,
  session_id TEXT NOT NULL,
  timestamp TIMESTAMPTZ DEFAULT NOW(),
  action_type TEXT NOT NULL,
  action_category TEXT,         -- 'purchase', 'movement', 'interaction', 'hesitation'
  amount DECIMAL(12,2),
  hesitation_ms INTEGER,
  coordinates JSONB,             -- spatial position if in-simulation
  metadata JSONB,
  entropy_score DECIMAL(8,6),    -- calculated Shannon entropy for this action
  predicted_next_state TEXT       -- HMM output prediction
);

-- User predictive profiles (Elon models)
CREATE TABLE user_elon_models (
  user_id TEXT PRIMARY KEY,
  current_entropy DECIMAL(8,6) NOT NULL DEFAULT 0.5,
  entropy_history JSONB,         -- sliding window of entropy values
  hmm_state_vector JSONB,        -- current hidden Markov state probabilities
  trajectory_prediction JSONB,   -- predicted next 5 actions with probabilities
  persona_allocation JSONB,      -- which nodes/personas are tracking this user
  last_updated TIMESTAMPTZ DEFAULT NOW(),
  data_fidelity_score DECIMAL(4,3) DEFAULT 0.000  -- confidence in prediction accuracy
);

-- Node state matrix
CREATE TABLE node_matrix_state (
  node_id TEXT PRIMARY KEY,
  pillar TEXT NOT NULL CHECK (pillar IN ('HOPE', 'DREAM', 'VISION', 'APEX', 'KNOLL')),
  matrix_x INTEGER NOT NULL,
  matrix_y INTEGER NOT NULL,
  persona_count INTEGER DEFAULT 100,
  current_frequency TEXT NOT NULL DEFAULT 'BETA',
  compute_load DECIMAL(5,2) DEFAULT 0.00,
  status TEXT DEFAULT 'ACTIVE',
  last_ping TIMESTAMPTZ DEFAULT NOW()
);

-- Business integration layer
CREATE TABLE business_integrations (
  business_id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  business_name TEXT NOT NULL,
  integration_type TEXT NOT NULL,  -- 'physical', 'digital_sim', 'hybrid'
  exclusive BOOLEAN DEFAULT TRUE,
  revenue_share DECIMAL(3,2),      -- 0.02 to 0.05 (2-5%)
  telemetry_endpoint TEXT,
  active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Economic transaction ledger
CREATE TABLE transaction_ledger (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id TEXT NOT NULL,
  business_id UUID REFERENCES business_integrations(business_id),
  amount DECIMAL(12,2) NOT NULL,
  currency_type TEXT NOT NULL,       -- 'coins', 'chips', 'fragments', 'tokens', 'charges', 'prestige'
  hesitation_ms INTEGER,
  entropy_at_transaction DECIMAL(8,6),
  predicted BOOLEAN DEFAULT FALSE,   -- was this transaction predicted by the Elon model?
  timestamp TIMESTAMPTZ DEFAULT NOW()
);
```

## Appendix B: Key Mathematical Formulas

**Shannon Entropy:**
```
H(X) = -Σ P(xᵢ) log₂ P(xᵢ)
```

**Hidden Markov Model (Forward Algorithm):**
```
αₜ(j) = Σᵢ αₜ₋₁(i) · aᵢⱼ · bⱼ(oₜ)
```
Where:
- αₜ(j) = probability of being in state j at time t
- aᵢⱼ = transition probability from state i to state j
- bⱼ(oₜ) = probability of observing oₜ given state j
